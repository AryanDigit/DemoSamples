# Queentana Fresh — Website Clone

Static multi-page clone of [queentana.co.uk](https://www.queentana.co.uk/) — wholesale fresh fruit & vegetables for the UK & EU.

## Quick start

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8080 --directory .
```

Then visit `http://localhost:8080`.

## Pages

| Path | Description |
|------|-------------|
| `index.html` | Homepage — hero, categories, story, FAQs, contact form |
| `pages/about.html` | About Queentana Fresh |
| `pages/produce.html` | Full produce range by category |
| `pages/customers.html` | Become a customer |
| `pages/suppliers.html` | Become a supplier |
| `pages/contact.html` | Contact details + enquiry form |
