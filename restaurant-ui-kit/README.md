# Restaurant UI Kit

Ultra Premium Restaurant Website HTML UI Kit — ThemeForest ready.

## Highlights

- **10 unique demos** (Luxury, Italian, Sushi, Indian, Mexican, BBQ, Seafood, Cafe, Fast Food, Bakery)
- **100+ HTML pages** per demo set
- **200+ reusable UI components**
- **SCSS 7-1 architecture** + minified CSS/JS
- Dark / Light themes, GSAP & AOS animations, Lenis smooth scroll
- SEO (schema, sitemap, robots) & accessibility foundations

## Quick Start

```bash
cd restaurant-ui-kit
npm install
npm run build:css
npm run serve
```

Open `http://localhost:5500`.

## Regenerate package

```bash
npm run build
```
