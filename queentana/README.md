# Queentana Fresh — Wholesale Produce Website

Professional multi-page website for **Queentana Fresh**, inspired by [queentana.co.uk](https://www.queentana.co.uk/) — wholesale fruit & vegetables for the UK & EU, including import/export.

## Official reference

**https://www.queentana.co.uk/**

- Email: trading@queentana.co.uk
- Phone: +44 (0) 208 538 0269

## Quick start

1. Open **`index.html`** in your browser, or unzip `dist/queentana-html-template.zip`.
2. Browse Produce, Services, Import & Export, About, and Contact.

```bash
npm start
```

## Structure

| Path | Description |
|------|-------------|
| `index.html` | Professional company homepage |
| `pages/` | About, Produce, Services, Import/Export, Contact |
| `demos.html` | 10 alternate homepage demos |
| `assets/` | CSS & JS |

## Regenerate

```bash
node scripts/build-pages.js
```
