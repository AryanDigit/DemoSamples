Giftora Premium Documentation

ThemeForest-quality gift shop HTML template with 10 unique demos.

1. Getting Started

  1. Unzip / open the giftora-premium folder.
  2. Open index.html in a modern browser (Chrome, Firefox, Edge, Safari).
  3. Click any Live Preview card to enter a demo.

No build step or server is required for local preview. For best results with some browsers’ local file rules, you may serve the folder with a simple static server:

npx serve .
# or
python3 -m http.server 8080

2. Folder Structure

giftora-premium/
  index.html                 # Root landing / demo switcher
  assets/                    # Landing CSS & JS
  documentation/             # This documentation
  demo-01-luxury/ … demo-10-modern/
    index.html shop.html product.html about.html
    gallery.html blog.html faq.html contact.html
    assets/css/style.css
    assets/js/main.js
    assets/images/ assets/fonts/

3. Technologies

  • HTML5 · CSS3 · Bootstrap 5.3
  • Vanilla JavaScript (ES6)

5. Customization

  • Colors & type: edit CSS variables in each demo’s assets/css/style.css (:root).
  • Content: replace text/images in the HTML files.
  • Cart/wishlist: demo state is stored in localStorage via assets/js/main.js.
  • Forms: newsletter & contact show a demo alert — wire to your endpoint or Formspree.
